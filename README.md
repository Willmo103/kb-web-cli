# kb-web-cli

Standalone administrative CLI client command station to interact with a LIVE `kb-web` server.

## Installation

You can install this package independently on client computer terminals:

```bash
# From within the workspace
pip install ./kb-web-cli
# Or from packaged wheels
pip install kb_web_cli-0.1.0-py3-none-any.whl
```

## Basic Commands

Configure the client with the remote server URL and an administrative API key:

```bash
kb-cli install
```

List available commands:

```bash
kb-cli --help
```
